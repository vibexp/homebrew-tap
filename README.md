# vibexp/homebrew-tap

Homebrew tap for the [VibeXP CLI](https://github.com/vibexp/cli) (`vibexp`).

## Install

```bash
brew install vibexp/tap/vibexp
vibexp version
```

The `Casks/vibexp.rb` formula is generated and pushed automatically by
[goreleaser](https://goreleaser.com) on every `vibexp/cli` release — do not edit
it by hand. See the CLI's [release runbook](https://github.com/vibexp/cli/blob/main/docs/releasing.md).
